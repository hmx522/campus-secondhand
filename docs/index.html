本页面是什么

这是把训练好的四个模型参数（词表、系数、标准化参数、聚类质心）编译进网页的纯前端版本：不需要服务器、不需要 Python，浏览器打开就能算。

和 Python 版的关系
模型同一套、参数同源、数据同一份；价格与推荐的结果与 Flask 版逐位一致，违规检测因浏览器没有 jieba 改用词表最大匹配，结论方向一致。
为什么这样做
GitHub Pages 只能托管静态文件，放不了 Python 服务。把推理放进浏览器，就能得到永久可用、不会休眠的公开网址。
离线也能用
页面无任何外部请求，下载到本地双击也能跑；断网、换电脑、手机浏览器都可用。
